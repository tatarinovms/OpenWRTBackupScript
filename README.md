# OpenWRT Backup Script

Автоматический скрипт для создания бекапов конфигурации OpenWRT роутеров с загрузкой на Яндекс Диск.

## Возможности

- ✅ Создание бекапов конфигурации OpenWRT через `sysupgrade -b`
- ✅ Автономная работа роутера с rclone
- ✅ Прямая загрузка на Яндекс Диск с роутера
- ✅ Хранение только последних 3 бекапов в облаке
- ✅ Уведомления в Telegram об успешности/ошибках
- ✅ Автоматическая очистка временных файлов
- ✅ Простая настройка прямо в скрипте

## Как работает скрипт

1. **Создание бекапа**: Использует `sysupgrade -b` для создания tar.gz архива конфигурации
2. **Управление облаком**: Удаляет старые бекапы, оставляя только последние 3
3. **Загрузка**: Копирует новый бекап на Яндекс Диск через rclone
4. **Очистка**: Удаляет временные файлы с роутера
5. **Уведомления**: Отправляет статус в Telegram (если настроено)

## Полная инструкция по установке на OpenWRT

### Шаг 1: Установка rclone на роутер OpenWRT

**Через SSH подключение к роутеру:**
```bash
# Подключитесь к роутеру
ssh root@192.168.1.1

# Обновите список пакетов
opkg update

# Установите rclone
opkg install rclone

# Проверьте установку
rclone --version
```

### Шаг 2: Настройка rclone для Яндекс Диска

**Запустите конфигурацию rclone:**
```bash
rclone config
```
И настройте ваше подключение к Яндекс Диску

### Шаг 3: Копирование скрипта на роутер

**Создайте папку для скриптов и скопируйте файл:**

**Вариант 1: Прямое скачивание с GitVerse (рекомендуется)**
```bash
# Подключитесь к роутеру
ssh root@192.168.1.1

# Создайте папку и скачайте скрипт
mkdir -p /root/scripts
curl -o /root/scripts/router-backup.sh https://gitverse.ru/api/repos/tatarinovms/OpenWRTBackupScript/raw/branch/master/router-backup.sh

# Сделайте исполняемым
chmod +x /root/scripts/router-backup.sh
```

**Вариант 2: Через SCP с локального компьютера**
```bash
# С локального компьютера
ssh root@192.168.1.1 "mkdir -p /root/scripts"

# Скопируйте скрипт
scp router-backup.sh root@192.168.1.1:/root/scripts/

# Или через веб-интерфейс роутера в System → File Transfer

# Сделайте скрипт исполняемым:
ssh root@192.168.1.1 "chmod +x /root/scripts/router-backup.sh"
```

### Шаг 4: Настройка Telegram (опционально)

**Как создать бота в Telegram:**
1. Найдите @BotFather в Telegram
2. Отправьте `/newbot`
3. Введите имя бота (например, "My Router Bot")
4. Введите username бота (например, "my_router_backup_bot")
5. Получите токен бота (строка вида `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

**Как узнать Chat ID:**
1. Добавьте бота в чат или напишите ему в личные сообщения
2. Перейдите по ссылке: `https://api.telegram.org/bot[ВАШ_ТОКЕН]/getUpdates`
3. Найдите поле `"chat":{"id":` - это ваш Chat ID

### Шаг 5: Настройка скрипта

**Отредактируйте настройки в начале файла:**
```bash
vi /root/scripts/router-backup.sh
```

**Измените параметры:**
```bash
RCLONE_SERVICE="yandex"           # Название вашего rclone сервиса
YANDEX_PATH="Backup/router"       # Папка на Яндекс Диске
TELEGRAM_BOT_TOKEN="Токен бота из пункта 4"  # Токен бота (оставьте пустым для отключения)
TELEGRAM_CHAT_ID="Chat ID из пункта 3"       # Chat ID (оставьте пустым для отключения)
```

### Шаг 6: Ручная проверка скрипта

**Запустите скрипт вручную:**
```bash
/root/scripts/router-backup.sh
```

**Если все работает, вы увидите:**
- Бекап создается на роутере
- Загружается на Яндекс Диск и файлы появились в нем.
- Временные файлы удаляются
- Уведомление в Telegram (если настроено)

### Шаг 7: Автоматизация через cron

**Добавьте задачу в cron для запуска каждую неделю в понедельник в 10:00:**
```bash
# Откройте редактор cron
crontab -e

# Добавьте строку (каждый понедельник в 10:00)
0 10 * * 1 /root/scripts/router-backup.sh >/dev/null 2>&1

# Сохраните и выйдите (ESC, :wq для vi)
```

**Формат времени cron:**
- `0 10 * * 1` = Минута Час День Месяц День_недели
- `0` = минута (0-59)
- `10` = час (0-23)
- `*` = любой день месяца
- `*` = любой месяц
- `1` = понедельник (0=воскресенье, 1=понедельник, ..., 6=суббота)

**Другие варианты расписания:**
```bash
# Каждый день в 3:00
0 3 * * * /root/scripts/router-backup.sh >/dev/null 2>&1

# Каждые 12 часов
0 */12 * * * /root/scripts/router-backup.sh >/dev/null 2>&1

# Каждую субботу в 2:00
0 2 * * 6 /root/scripts/router-backup.sh >/dev/null 2>&1

# Каждый первый день месяца в 4:00
0 4 1 * * /root/scripts/router-backup.sh >/dev/null 2>&1
```

**Проверьте установленные задачи:**
```bash
crontab -l
```

**Перезапустите службу cron:**
```bash
/etc/init.d/cron enable
/etc/init.d/cron restart
```
